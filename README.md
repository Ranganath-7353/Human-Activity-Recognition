# Human Activity Recognition

A machine learning project for recognizing human activities from sensor data.

## Project Structure

- **app/**: Flask/web application for predictions
- **data/**: Dataset files (DS DATA.csv)
- **models/**: Trained model files
- **notebook/**: Jupyter notebooks for analysis and model development
- **src/**: Source code for predictions and utilities

## Setup

1. Create a virtual environment
2. Install dependencies
3. Run the application

## Usage

Use the web application in the `app/` directory to make predictions on activity data.
